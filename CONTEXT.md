### **Вариант Б: Подробный промт (для максимальной точности)**
Этот вариант содержит больше деталей и будет полезен, если новый помощник захочет глубже разобраться в архитектуре.

> **Контекст для продолжения обучения Node.js**
>
> **1. Прогресс и текущий статус**
> Я прошел этапы 1-4 и часть 5 по следующему плану:
> *   **Этап 1-2:** JavaScript основы, Node.js ядро (пропущено, т.к. это база).
> *   **Этап 3:** Express + TypeScript (REST, middleware, controllers, error handling) — полностью освоено.
> *   **Этап 4:** База данных (PostgreSQL, CRUD, модели, связи) — полностью освоено.
> *   **Этап 5:** Авторизация (JWT) и роли — реализовано.
>
> **2. Стек технологий проекта**
> *   **Язык:** TypeScript.
> *   **Сервер:** Express.js.
> *   **База данных:** PostgreSQL (библиотека `pg`).
> *   **Авторизация:** JWT (`jsonwebtoken`), хеширование (`bcryptjs`).
> *   **Валидация:** Zod (установлена, но внедрена частично).
> *   **Документация:** Начата интеграция Swagger (`swagger-jsdoc`, `swagger-ui-express`).
>
> **3. Архитектура проекта (src/)**
> *   `config/`: `db.ts` - подключение к PostgreSQL.
> *   `models/`: Содержит функции с SQL-запросами (task.model.ts, user.model.ts, auth.model.ts).
> *   `controllers/`: Содержит логику обработки запросов (taskController.ts, userController.ts, authController.ts, adminController.ts).
> *   `routes/`: Определяет эндпоинты и связывает их с контроллерами (taskRoutes.ts, userRoutes.ts, authRoutes.ts, adminRoutes.ts).
> *   `middleware/`: `auth.middleware.ts` (проверка JWT), `role.middleware.ts` (проверка ролей), `validate.middleware.ts` (валидация через Zod).
> *   `validations/`: Схемы Zod для валидации (auth.validation.ts, task.validation.ts).
> *   `types/`: TypeScript интерфейсы (user.types.ts, task.types.ts).
> *   `utils/`: `AppError.ts` - кастомный класс ошибок.
> *   `app.ts`: Главный файл приложения, подключает все middleware и роуты.
>
